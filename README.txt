מערכת ניהול מוסכים – FullStack
תרגיל כניסה למשרת פיתוח FullStack
פיתוח צד שרת ב־NET. ופיתוח צד לקוח ב־Angular 17

--------------------------------------------------------
2. הוראות התקנה והרצה – צד שרת (Server)
--------------------------------------------------------

דרישות מוקדמות:
- גרסת ‎.NET 7 / .NET 8 מותקנת
- מסד נתונים מותקן PostgreSQL

שלבים:

1. כניסה לתיקיית השרת:
   cd server

2. שחזור תלויות:
   dotnet restore

3. עדכון מחרוזת החיבור במסד הנתונים בקובץ:
   appsettings.json

4. הרצת השרת:
   dotnet run

השרת רץ בכתובת:
http://localhost:7155

--------------------------------------------------------
3. הוראות התקנה והרצה – צד לקוח (Client)
--------------------------------------------------------

דרישות מוקדמות:
- התקנת Node.js
- התקנת Angular CLI (גרסה 17+)

שלבים להרצה:

1. כניסה לתיקיית הקליינט:
   cd client

2. התקנת ספריות:
   npm install

3. הרצת האפליקציה:
   ng serve

האפליקציה תעלה בכתובת:
http://localhost:4200


--------------------------------------------------------
4. נקודות קצה (API)
--------------------------------------------------------

• ‎GET /api/garages/fetch  
  שליפת נתוני מוסכים מה־API הממשלתי ושמירתם במסד הנתונים.

• ‎GET /api/garages  
  החזרת כל המוסכים השמורים במסד הנתונים.

• ‎POST /api/garages  
  הוספת מוסכים חדשים למסד הנתונים (לאחר ולידציה בצד לקוח).


--------------------------------------------------------
5. מסד נתונים בשימוש
--------------------------------------------------------

הפרויקט משתמש ב־ PostgreSQL
